# Tirzepatide — The Dual Agonist | Claims vs Evidence

An interactive, educational infographic about tirzepatide (LY3298176): the dual GIP/GLP-1 receptor agonist sold as Mounjaro (type 2 diabetes) and Zepbound (weight management, sleep apnea) — the 39-amino-acid molecule, its twincretin origin story, the dual-receptor pathways, the SURMOUNT trial results, how it compares across incretin generations, the published trial dose arms, what people online report, safety signals, a plain-English glossary, and key takeaways.

**Live page:** https://discoveranytime.github.io/tirzepatide/

## What's inside

- Long scrolling journey with a sticky chapter rail / fixed sidebar table of contents (scrollspy with a gliding highlight pill, live 0–100% reading progress)
- 10 chapters: the molecule, origin story, how it works, evidence check, what people say, trial dosing, risks & unknowns, glossary, takeaways, limits
- Animated inline-SVG diagrams (amino-acid bead chain, twincretin timeline, dual-receptor signaling, generation comparison, dose-escalation ladder)

- Single self-contained `index.html` — no external resources, works opened directly in a browser
